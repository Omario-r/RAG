# Лабы — прохождение руками

Третий слой волта. Теория отвечает «как это устроено вообще» ([[База знаний/README|База знаний]]), справочники корня — «как это решено у нас», лаба — **«как это проходилось руками»**: последовательность действий с дословным выводом команд на дату прохождения.

Лаба пишется, чтобы понять, а не чтобы потом читать как справочник. Отсюда её формат: короткие шаги, видимый результат после каждого, вопрос-предсказание перед командой. Правила — [lab-style.md](lab-style.md), они живые и пополняются.

## Главное свойство: лабы заморожены

Лаба — запись на дату, она **не поддерживается** в актуальном состоянии. Расхождение старой лабы с текущим кодом — не дефект, а нормальное свойство записи. Иначе правка кода порождала бы обязательство править семь лаб.

Заморозка касается содержимого. Навигационная шапка — узел, ссылки на теорию и справочник — обновляется, потому что это адрес, а не запись прохождения.

## Проверка

Механическая проверка лаб по чек-листу `lab-style` — длина шагов, положение первой команды, маркеры блоков вывода, целость ссылок:

```bash
python3 tools/check-labs.py 'lab-0*.md'
```

Она не проверяет главного: что вывод снят выполнением, а не пересказан, и что объяснение понятно. Это ловится только прохождением.
