# Определение RAG

**RAG — Retrieval-Augmented Generation**, генерация ответа, дополненная извлечением информации. Это не отдельная модель, а архитектурный паттерн: комбинация системы поиска (retriever) и генеративной модели (LLM), которые работают вместе.

## Три шага

1. **Retrieval (извлечение).** По вопросу пользователя система находит
в базе знаний фрагменты текста, которые, вероятно, содержат ответ.
2. **Augmentation (дополнение).** Найденные фрагменты добавляются
к исходному вопросу — формируется расширенный запрос («вопрос + релевантный контекст»), который и передаётся модели.
3. **Generation (генерация).** LLM формирует ответ, опираясь на
предоставленный контекст, а не только на собственные веса.

## Аналогия: экзамен с открытой книгой

Модель без RAG — это студент, который сдаёт экзамен по памяти: если конкретный факт не был выучен заранее, приходится гадать. Модель с RAG — это тот же студент, но с доступом к конспектам во время экзамена: он не обязан помнить всё, достаточно уметь быстро найти нужный раздел и сформулировать ответ на его основе.

Ключевое отличие от простого дообучения в том, что «конспект» можно обновлять в любой момент, не переучивая студента заново.

## Что даёт RAG по сравнению с обычным ответом модели

- **Обоснованность (grounding).** Ответ строится на конкретных
фрагментах текста, которые в принципе можно показать пользователю — «вот источник, откуда это взято».
- **Актуальность без переобучения.** Изменения в базе знаний
подхватываются сразу — данные просто переиндексируются, вес модели трогать не нужно.
- **Прозрачная граница ответственности.** Модели можно явно
инструктировать: «отвечай только на основе предоставленного контекста, если ответа нет — сообщи, что не знаешь» — это резко снижает вероятность выдумывания фактов, хотя не устраняет её полностью.

## Что RAG не делает

RAG не превращает модель в источник истины и не гарантирует стопроцентную точность — качество ответа зависит от качества поиска (нашли ли вообще нужный фрагмент), качества самого документа и того, насколько строго модель следует инструкции опираться только на контекст.
