# Словарь терминов

Одно понятие — одно слово. Список заведён 05.09.2026 после вычитки 4.1.1, где
одна вещь называлась тремя словами, а одно слово значило три вещи.

Столбец «вместо» — единственное, ради чего словарь существует: по нему
проверяется весь волт одной командой. Столбец «в сообществе» отделяет термины
области от слов, придуманных ролью: придуманное помечено прочерком, и всякое
такое слово можно менять свободно.

## Нарезка и адресация

| Термин      | Что означает                                           | Вместо             | В сообществе |
| ----------- | ------------------------------------------------------ | ------------------ | ------------ |
| чанк        | отрезок, на которые нарезан документ перед индексацией | кусок, фрагмент    | chunk        |
| лимит чанка | предельная длина чанка, задаётся при нарезке           | окно, размер куска | chunk size   |
| перекрытие  | общая часть соседних чанков                            | скользящее окно    | overlap      |
| смещение    | номер символа от начала документа                      | позиция, offset    | offset       |
| диапазон    | пара смещений, адрес отрезка в документе               | интервал, span     | span         |

## Разметка и измерение

| Термин                | Что означает                                                | Вместо                           | В сообществе               |
| --------------------- | ----------------------------------------------------------- | -------------------------------- | -------------------------- |
| тестовый набор, набор | вопросы с разметкой, метриками и конфигурацией прогона      | эталонный набор, бенчмарк        | test collection            |
| разметка              | привязка вопроса к местам в корпусе                         | суждения, разметка релевантности | relevance judgments, qrels |
| размеченное место     | отрезок документа, признанный верным ответом                | пункт, релевантный кусок         | relevant passage           |
| степень релевантности | насколько полно место отвечает на вопрос, число из шкалы     | балл, оценка                     | relevance grade            |
| прогон                | один запуск набора через систему с записанной конфигурацией | эксперимент, запуск              | run                        |
| выдача                | список чанков, вернувшихся от поиска                        | результаты, топ                  | result list                |
| ранг                  | место чанка в выдаче, считая с первого                      | позиция, номер                   | rank                       |
| порог отказа          | граница, ниже которой система отвечает «не знаю»            | порог уверенности                | abstention threshold       |
| бенчмарк              | открытый набор вопросов с готовой разметкой                 | датасет                          | benchmark                  |
| пассаж                | единица текста, которую в бенчмарке и размечают, и выдают   | —                                | passage                    |
| контекст              | текст, подаваемый модели вместе с вопросом                  | промпт, подача                   | context                    |
|                       |                                                             |                                  |                            |

## Придуманное ролью

Слова из этого раздела в сообществе не приняты. Менять их можно свободно, но
менять надо везде сразу.

| Термин | Что означает | Как называют в области |
|---|---|---|
| программа замера | считает метрики по выдаче и разметке | evaluation tool, `trec_eval` |
| уровень счёта | что берут за единицу найденного ответа: документ или чанк | document-level, passage-level judgments |
| покрытие места | длина пересечения, делённая на длину размеченного места | устойчивого имени нет |
| покрытие чанка | длина пересечения, делённая на длину чанка | устойчивого имени нет |
| направление доли | выбор знаменателя в доле пересечения | устойчивого имени нет |
| совпадение не один к одному | место в нескольких чанках либо чанк с несколькими местами | устойчивого имени нет |

## Как проверять

Команда ищет по волту слова из столбца «вместо».

```bash
grep -rnE "кус(ок|ка|ки|ков|ке|ком)|фрагмент|скользящ|топ-[0-9]|датасет" \
  --exclude=словарь.md RAG-система/
```

Правило заведения нового термина: сначала посмотреть, как вещь называют в
области, и взять оттуда. Своё слово заводить, только когда общепринятого нет, и
класть его в раздел придуманного.
