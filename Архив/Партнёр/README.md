## Правило работы с этой папкой

Партнёрский стенд — **ещё одна площадка для экспериментов**, а не отдельный проект и не приоритет. Из основного потока волта сюда ведут ссылки, обратно — нет: справочники узлов не должны зависеть от того, что стоит у партнёра.

Вопрос партнёру уходит точечно и только тот, который мы сами поняли — дисциплина описана в [02-questions.md](02-questions.md).
