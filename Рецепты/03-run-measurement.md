# Прогнать замер и занести прогон

> [!info] Рецепт — живая инструкция
> Что означают метрики и почему пара `hit@k` / `recall@k` не разводится — [05-retrieval-rerank.md](../05-retrieval-rerank.md) и [checks/criteria.md](../checks/criteria.md).

## 1. Прогнать

```bash
cd ~/Development/Home/RAG-stand && uv run python scripts/evaluate.py --rerank
```

| Флаг | Что делает |
|---|---|
| без флагов | только векторный поиск |
| `--rerank` | каскад top-50 → реранкер |
| `--rerank --depth 10` | реранкуется только голова списка |
| `--rerank --head` | реранкеру даётся шапка чанка — замерено, что вредит |
| `--json` | строка для машинного журнала `experiments.jsonl` |

**Менять по одному параметру за раз.** Прогон «поменяли чанкинг и модель, стало лучше» не отвечает ни на один вопрос.

## 2. Занести прогон

Прогон, не занесённый в [checks/runs.md](../checks/runs.md), не существует: сослаться на него можно будет только пересказом.

1. Имя: `RUN-<ГГГГММДД>-<буква>`, буква по порядку внутри дня.
2. Заполнить схему прогона целиком — конфигурация, метрики парами, провенанс с коммитом стенда.
3. Проставить ссылку там, где прогон что-то закрывает: этап в [06-roadmap.md](../06-roadmap.md), утверждение в [11-evidence.md](../11-evidence.md), урок в [09-experiments.md](../09-experiments.md).

## 3. Проверить связность

```bash
python3 tools/check-runs.py
```

Ловит ссылку на несуществующий прогон, прогон без конфигурации или без вывода, закрытый этап без прогона и прогон-сироту.
