# RAG-lab — техническая проработка семантического поиска по договорам

Волт технической части проекта. Бизнес-часть (ниши, сегменты, экономика,
страхи заказчика) живёт отдельно: `~/Development/Home/Business`.

Дата создания: 28.07.2026.

## Зачем этот волт

Задача от партнёра: научиться делать семантический поиск по корпусу договоров
в закрытом контуре — чанкинг → векторизация локальной моделью → Qdrant → поиск
→ реранкер. Первый практический шаг всей продуктовой линейки: этот пайплайн —
общее ядро для legal-ai, med-scribe и on-prem RAG из бизнес-волта.

Расширение сегмента (новая вводная, 28.07.2026): закрытый контур нужен не
только малым юрфирмам, но и **крупным компаниям для отслеживания договоров**.
Подробнее — [00-context.md](00-context.md).
